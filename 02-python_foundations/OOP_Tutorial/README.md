# Python Object-Oriented Programming Study Guide

[Back to Python Foundations](../README.md)

This six-part guide explains object-oriented programming in Python through a growing set of runnable `Employee` examples.

The examples are adapted from Corey Schafer's [Object-Oriented code snippets](https://github.com/CoreyMSchafer/code_snippets/tree/master/Object-Oriented):

- The Python examples have been adapted for this guide.
- Each lesson includes a narrative study guide and a runnable script.
- The six lessons are also available in one combined Jupyter notebook.

## Learning Formats

- **Lesson by lesson:** Follow the study guides and run the script linked beside each lesson.
- **Combined notebook:** Read all six lessons in one file and run cells selectively. Some example cells intentionally show intermediate or failing states; each lesson ends with a complete runnable script.

[Open the combined Jupyter notebook](python_oop_complete_guide.ipynb)
