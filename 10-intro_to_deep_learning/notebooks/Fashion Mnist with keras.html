Callbacks¶

A callback is an object that can perform actions at various stages of training (e.g. at the start or end of an epoch, before or after a single batch, etc).

You can use callbacks to:

  • Periodically save your model to disk
  • Do early stopping
  • ...and more

https://keras.io/api/callbacks/

checkpoint = ModelCheckpoint('model.h5', save_best_only=True)
model.fit(X_train, y_train, epochs=100, validation_split=0.2, callbacks=[checkpoint])

Model Saving¶

In [36]:
model.save("my_keras_model.h5")

  • Keras will use the HDF5 format to save both the model’s architecture (including every layer’s hyperparameters)

    and the values of all the model parameters for every layer (e.g., connection weights and biases).

  • It also saves the optimizer (including its hyper‐ parameters and any state it may have).
