Arabic ML Bootcamp

A 12-module, video-first bootcamp for complete beginners: AI fundamentals, Python, data analysis, machine learning, deep learning, and beyond. Each module pairs a lecture playlist with notebooks, notes, and code. Pick a module below to start.

Who this is for

  • Aspiring data scientists
  • Machine learning beginners
  • Students
  • Professionals transitioning into AI

No prior programming or data experience required.

What you'll be able to do

  • Explain AI, ML, and the data science lifecycle
  • Write Python, and scrape the web with it
  • Analyze and visualize data with pandas & matplotlib
  • Build and deploy Streamlit apps
  • Train ML models — regression, classification, clustering
  • Go further: deep learning, computer vision, and NLP

Watch → Read → Code → Apply — the rhythm of every module below.

PythonData AnalysisMachine LearningDeep LearningStreamlitAnalytical Thinking

Before you start

No prior knowledge is assumed. Start at Module 01 and work forward — each module builds on the last. Watch the lecture playlist linked in each module's card, then open the reading page, and work through the notebooks and exercises in the order indicated.

  • Total content: 184 videos, ~27 hours of lectures across 12 modules.
  • Every module has a README.md with a full video table (YouTube links, durations, PDFs, code) — plus a dedicated reading page.
  • Code-heavy modules (02, 03, 06, 08, 09, 10, 11, 12) ship runnable Jupyter notebooks in a CODE/ folder.
  • Video-first — the reading pages are companions that turn each module's topics into written concepts you can skim before or after the lectures.
