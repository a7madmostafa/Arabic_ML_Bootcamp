1What is data analysis?

The frame everything else hangs on: where analysis sits, what data comes in, and which question you're answering.

Data analysis is a process of examining data with the goal of discovering useful information, extracting insights, and informing conclusions to support decision-making — the science of collecting, analyzing, presenting, and interpreting data to get information from data.

1.1 The data science lifecycle

Analysis is one stage of a loop: understand the business and the data, preprocess it, analyze it, model it, deploy the result — and the deployed model teaches you new questions to ask.

1.2 Know your data types

Every column is either categorical or numerical — and the type decides which statistics and plots are even legal:

FamilyTypeMeaningExamples
CategoricalNominalNo orderCountry, color, gender
CategoricalOrdinalOrderedLevels, grades, ratings
NumericalDiscreteFinite countsNo. of students, products
NumericalContinuousInfinite valuesSalary, weight, temperature, speed
Type before tool

Averaging a nominal column (mean country?) is nonsense, and a histogram of two categories tells you nothing. Name the type first — §3 and §4 then tell you exactly which summary and plot each type deserves.

1.3 The four analysis types

Descriptive

Summarize quantitative data with statistics — distributions, min/average/max/total per group. Answers "What happened?"

Diagnostic

Once you know the what, find the why — sales swung for 10 years, why? Answers "Why did it happen?"

Predictive

Understand the past to guess the future — next year's sales? Answers "What might happen?"

Prescriptive

Turn the prediction into a plan — how to profit or avoid loss? Answers "What should we do?"

This module lives mostly in descriptive and diagnostic territory; predictive modeling starts in Module 09.

3Statistics in practice

Descriptive statistics: describing a dataset's features with summary numbers — plus the plots that make them honest. (Slides: Descriptive Statistics PDF.)

3.1 Center: mean, median, mode

Center gives one representative number for a feature. Mean is the average; median is the middle value (for even counts, the average of the two middle values); mode is the most frequent value.

one representative number
df.age.mean() # average — sensitive to extremes df.age.median() # middle value — robust to extremes df.age.mode() # most frequent value
Mean or median?

Salaries have outliers (a few huge paychecks drag the mean up), so the median represents "typical pay" better. Rule of thumb: skewed data → median; symmetric data → mean. (§3.4 shows how to see the skew.)

3.2 Five-number summary

StatMeaning
MinimumThe smallest value
Q125% of the data fall below
Q2 (median)50% of the data fall below
Q375% of the data fall below
MaximumThe largest value

In pandas, one call prints all five plus the count and mean: df.describe() — and df.age.quantile([0.25, 0.5, 0.75]) pulls the quartiles directly.

3.3 Spread: range, IQR, variance, standard deviation

Two datasets can share a mean of 7925 yet spread from 2650 to 12700 — the mean alone lies by omission. Spread measures how far data differs from the center:

how far from center?
df.age.max() - df.age.min() # range = max - min df.age.quantile(0.75) - df.age.quantile(0.25) # IQR = Q3 - Q1 df.age.var() # variance: average squared distance from the mean df.age.std() # standard deviation: sqrt(variance), back in original units
Which spread when?

Range is one outlier away from useless. IQR ignores the tails (the middle 50%). Standard deviation is the workhorse — same units as the data, so "age ± 4 years" means something.

3.4 Shape: histograms, density, skew

A histogram bins a numeric column — each bar covers a value range, its height shows frequency — revealing peaks, symmetry vs. skew, and outliers at a glance. A density plot is its continuous, smoothed cousin. Try all three engines on one column:

Intro to EDA
df.age.hist() # pandas: quickest plt.hist(df.age) # matplotlib: full control sns.histplot(x='age', data=df) # seaborn: prettiest + kde=True option

3.5 The normal distribution

The bell curve is statistics' favorite shape — symmetric around the mean, with the famous empirical rule: ≈68% of values within one standard deviation, ≈95% within two, ≈99.7% within three.

3.6 Outliers and the box plot

Outliers demand a decision, not a reflex: at minimum note they exist and how they move your summaries — remove or fix only clear typos. The box plot exists for exactly this inspection: min, Q1, median, Q3, max in one glyph, with loners plotted as individual dots.

two orientations, one call
sns.boxplot(x="age", data=df) # horizontal sns.boxplot(y="age", data=df) # vertical

3.7 Covariance vs. correlation

Covariance

Do paired values rise together, or does one rise as the other falls? Direction only — values range from -∞ to +∞, so magnitude means little.

Correlation

How strong is the (linear) relationship? Dimensionless, from -1 to +1 — the closer to either end, the tighter the link. Salary vs. years of experience is the lecture's example.

one number, whole matrix, picture
df.corr()['salary']['age'] # single pair df.corr() # every pair at once sns.heatmap(df.corr(), annot=True) # the matrix as colors
Correlation is not causation

Two columns can march together for no causal reason at all. Correlation picks predictors and suspects of multicollinearity — it never proves why.

know thy table
df.info() # columns, non-null counts, dtypes df.dtypes # per-column types (§1.2 decides what each deserves) df.describe() # §3.2's five numbers, for free

4.3 Clean before you trust

duplicates, nulls, names
df.duplicated().sum() # any repeated rows? df.isnull().sum() # nulls per column df.columns = ['exp', 'age', 'salary', 'country'] # short, lowercase names df.to_csv('salary_modified.csv') # save the cleaned table

4.4 Univariate → bivariate → multivariate

One variable at a time (numeric: hist/box + §3 stats; categorical: value_counts() + bar/pie), then pairs (groupby means, scatter, regression line), then everything at once (pairplot, hue/size scatter, correlation heatmap):

one, two, all
df.country.value_counts() # univariate categorical df.groupby('country').salary.agg(['mean', 'std']) # bivariate summary sns.pairplot(df) # multivariate: every pair at once
