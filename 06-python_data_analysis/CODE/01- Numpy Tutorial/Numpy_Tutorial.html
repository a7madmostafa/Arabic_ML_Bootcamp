⚙️ Chapter 1: Setup & Why NumPy¶

🎯 Goal:¶

Understand when to use NumPy instead of plain Python lists — speed, vectorization, and the array math behind data analysis and ML.

📦 Import & Version¶

  • What: import numpy as np is the universal alias.
  • Why: Every snippet below depends on it.
  • When to use: First cell of any numerical notebook.
In [1]:
import numpy as np
np.__version__
Out[1]:
'2.1.3'

🆚 Lists vs Arrays¶

  • What: Python lists concatenate with +; NumPy arrays add element by element.
  • Why: Vectorized math is shorter, faster, and exactly what ML models expect as input.
  • When to use: Any numeric computation over more than a handful of numbers.
In [2]:
[1, 2, 3] + [1, 2, 3]  # list: concatenates
Out[2]:
[1, 2, 3, 1, 2, 3]
In [3]:
np.array([1, 2, 3]) + np.array([1, 2, 3])  # array: adds element by element
Out[3]:
array([2, 4, 6])

📌 Insight: If + concatenates instead of adding, you are holding a list, not an array — wrap it with np.array(...) first.

📊 Chapter 7: Aggregation & Axis¶

🎯 Goal:¶

Summarize arrays with aggregations (sum/mean/min/max/std) and control which direction they run with axis — the direct prep for central tendency and spread in Descriptive Statistics.

🧾 Sample Data (synthetic weekly sales)¶

  • What: A 3×3 array — 3 branches (rows) × 3 products (columns).
  • Why: One tiny array demonstrates every aggregation pattern.
  • When to use: Any time you collapse detail into totals or averages.
In [132]:
sales = np.array([[120, 200, 150],
                  [180, 160, 210],
                  [140, 190, 170]])
sales
Out[132]:
array([[120, 200, 150],
       [180, 160, 210],
       [140, 190, 170]])

➕ Whole-Array Totals & Average¶

In [133]:
np.sum(sales)   # grand total
Out[133]:
np.int64(1520)
In [134]:
np.mean(sales)  # overall average (central tendency)
Out[134]:
np.float64(168.88888888888889)

📏 Spread: min / max / std¶

In [135]:
np.min(sales), np.max(sales)  # range ends
Out[135]:
(np.int64(120), np.int64(210))
In [136]:
np.std(sales)   # spread of the data (standard deviation)
Out[136]:
np.float64(27.666443551086072)

🧭 Axis: which direction?¶

  • What: axis=0 collapses rows (result per column); axis=1 collapses columns (result per row).
  • Why: Answers "per product" vs "per branch" questions.
  • When to use: Every grouped summary — the same idea as pandas groupby.
In [137]:
np.sum(sales, axis=0)  # per product (column totals)
Out[137]:
array([440, 550, 530])
In [138]:
np.sum(sales, axis=1)  # per branch (row totals)
Out[138]:
array([470, 550, 500])
In [139]:
np.mean(sales, axis=0)  # average sales per product
Out[139]:
array([146.66666667, 183.33333333, 176.66666667])
In [140]:
np.max(sales, axis=1)   # best-selling product per branch
Out[140]:
array([200, 210, 190])

📌 Insight: axis= names the dimension that disappears — axis=0 on a (3, 3) array returns shape (3,), one value per column.

🔀 Chapter 8: Reshape & Broadcasting¶

🎯 Goal:¶

Change array shapes without changing data (reshape) and predict how mismatched shapes combine (broadcasting rules) — the #1 source of ML shape errors.

📐 Reshape¶

  • What: reshape reorganizes the same data into a new shape.
  • Why: Turn flat data into rows/columns (or back) for models and plots.
  • When to use: Preparing feature matrices; -1 means "infer this dimension".
In [141]:
flat = np.arange(1, 7)
flat
Out[141]:
array([1, 2, 3, 4, 5, 6])
In [142]:
flat.reshape(2, 3)   # 2 rows x 3 cols
Out[142]:
array([[1, 2, 3],
       [4, 5, 6]])
In [143]:
flat.reshape(-1)     # flatten back (infer the size)
Out[143]:
array([1, 2, 3, 4, 5, 6])
In [144]:
flat.reshape(6, 1)   # column vector — compare with Chapter 2
Out[144]:
array([[1],
       [2],
       [3],
       [4],
       [5],
       [6]])

📡 Broadcasting Rules¶

  • What: NumPy stretches dimensions of size 1 (or missing ones) to match the other operand.
  • Why: Adds per-row / per-column adjustments without loops.
  • When to use: Normalizing columns, adding biases, scaling features.
In [145]:
col = np.array([[10], [20], [30]])   # shape (3, 1)
row = np.array([1, 2, 3])            # shape (3,)
col + row  # (3,1) + (3,) -> (3,3)
Out[145]:
array([[11, 12, 13],
       [21, 22, 23],
       [31, 32, 33]])
In [146]:
sales + np.array([10, 0, -5])  # per-product adjustment across all branches
Out[146]:
array([[130, 200, 145],
       [190, 160, 205],
       [150, 190, 165]])

📌 Insight: If shapes mismatch unexpectedly, print .shape on both sides first — broadcasting aligns from the right, and a missing dimension is treated as size 1.
