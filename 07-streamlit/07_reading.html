Streamlit

Turn a Python script into an interactive web app — text, widgets, charts, multipage layouts, and deployment — all in pure Python, no HTML or JavaScript required.

What you'll be able to do after this lesson

  • Run any script as a web app with streamlit run.
  • Display text, markdown, media, DataFrames, and charts with st.* calls.
  • Collect input with buttons, checkboxes, selectors, sliders, and text/date/time fields.
  • Show progress, spinners, and success/error/warning/info messages.
  • Move controls into a sidebar and embed matplotlib and plotly figures.
  • Structure multipage apps — the pages/ convention or a single-file navigator.
  • Freeze dependencies with pipreqs and deploy to Streamlit Cloud.
Reading Streamlit Tutorial
Before you start

Install Streamlit, and understand the module's core rhythm — the notebook writes each demo to a .py file with the %%writefile magic, then launches it:

terminal
pip install streamlit streamlit run my_app.py

Every section below follows one demo app from the Streamlit Tutorial notebook — copy its code into a .py file and run it the same way.

1Hello, Streamlit

The smallest possible app — and the mental model behind every bigger one.

Streamlit Tutorial
import streamlit as st st.title("my first app")

Save that as app.py, run streamlit run app.py, and a browser tab opens with your title. Try streamlit hello any time for the official demo tour.

The rerun model

There is no event loop to manage: when a user moves a slider, Streamlit reruns your whole script top to bottom with the new value in place. Write plain sequential Python and the framework handles the interactivity.

2Displaying things

Text first, then media, then data — the output half of every app.

2.1 Text elements

01-displayText.py
st.title("this is the app title") st.header("this is the markdown") st.markdown("this is the header") st.subheader("this is the subheader") st.caption("this is the caption") st.code("x=2021") st.latex(r''' a+a r^1+a r^2+a r^3 ''')

st.markdown understands full Markdown — headers, italics, bold, strikethrough, blockquotes, links, images — and even raw HTML when you opt in with unsafe_allow_html=True (centering and coloring text, in the lecture's example).

2.2 Media and DataFrames

03-displayMedia.py · 04-displayDF.py
st.image("kid.png") # st.audio / st.video work the same way df = pd.DataFrame({'k':[1,2,3,4,5], 'v':[10,20,30,40,50]}) st.dataframe(df) # scrollable, sortable table

3Input widgets

The input half: every widget returns the user's choice as a plain Python value.

05-inputWidgets.py — choices
st.checkbox('yes') st.button('Click') st.radio('Pick your gender',['Male','Female']) st.selectbox('Pick your gender',['Male','Female']) st.multiselect('choose a planet',['Jupiter', 'Mars', 'neptune']) st.select_slider('Pick a mark', ['Bad', 'Good', 'Excellent']) st.slider('Pick a number', 0,50)
06-inputWidgets_2.py — entries
st.number_input('Pick a number', 0,10) st.text_input('Email address') st.date_input('Travelling date') st.time_input('School time') st.text_area('Description') st.file_uploader('Upload a photo') st.color_picker('Choose your favorite color')
Widgets are values

Each call returns the current choice — name = st.text_input('Email address') gives you a string to validate, store, or feed to a model. That return value plus the rerun model (§1) is how forms, filters, and dashboards work.

4Progress and status

Keep users oriented while work happens — and speak up clearly when it finishes or fails.

07-progress.py · 08-status.py
st.progress(75) with st.spinner('Wait for it...'): time.sleep(10) st.balloons() st.success("You did it !") st.error("Error") st.warning("Warning") st.info("It's easy to build a streamlit app") st.exception(RuntimeError("RuntimeError exception"))

5Sidebar

One prefix moves any element out of the main flow.

09-sidebar.py
st.sidebar.title("This is the sidebar") st.sidebar.header("This is the header") st.sidebar.button("Click") st.sidebar.checkbox("Yes") st.sidebar.radio("Pick your gender: ", ['male', 'female'])

Prefix any widget or text call with st.sidebar — navigation, filters, and settings live there; results stay center stage.

6Charts

Your Module 06 plots, embedded with one line each.

Matplotlib

fig, ax = plt.subplots() ax.hist(rand, bins=15) st.pyplot(fig)

Plotly

fig = px.histogram(rand, nbins=15) st.plotly_chart(fig)

The lecture builds three plotly views the same way — histogram, bar, and line charts via px.histogram, px.bar, and px.line, each rendered with st.plotly_chart. (Plotly figures stay interactive in the app: zoom, hover, pan.)

7Multipage apps

Two ways to grow past one screen.

7.1 The pages/ convention

Put the entry script next to a pages/ folder — every .py file inside becomes a navigable page automatically:

terminal layout
my_app.py pages/about.py pages/Contact.py

7.2 Single-file navigator

Prefer one file? Map page names to functions and let a sidebar selectbox do the routing:

my_app_2.py
page_names_to_funcs = { "Main Page": main_page, "Page 2": page2, "Page 3": page3, } selected_page = st.sidebar.selectbox("Select a page", page_names_to_funcs.keys()) page_names_to_funcs[selected_page]()

8Deployment

From your laptop to a public URL in two steps.

Hosting needs your dependency list. pipreqs scans your imports and writes it — then Streamlit Cloud builds and serves the app from your GitHub repo (the module's final lectures deploy the Covid-19 app exactly this way):

terminal
pip install pipreqs pipreqs ./
Commit the requirements file

Push requirements.txt alongside the app — without it, the cloud builder installs the wrong versions (or nothing) and the deploy fails with an import error.

◐Wrap-up — apps in one breath

The module compresses into a single loop.

the whole story
.py script --streamlit run--> local app --widgets--> values --charts/sidebar/pages--> real tool --pipreqs + push--> public URL
The one-sentence version

Streamlit turns sequential Python into a web app: st.* calls declare text, widgets, and charts; every interaction reruns the script with fresh values; the sidebar, multipage layouts, and Streamlit Cloud take the result from demo to deployment.
