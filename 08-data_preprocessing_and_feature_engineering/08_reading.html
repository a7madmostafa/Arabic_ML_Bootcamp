Data Preprocessing & Feature Engineering

From raw data to model-ready features — explored on a used-car dataset across 8 notebooks: explore, clean, impute, de-outlier, scale, transform, encode, then pipeline it all.

  • Detect outliers visually, with IQR, and with z-scores — then remove or winsorize.
  • Choose Min-Max vs. standardization vs. robust scaling based on the model and the outliers.

  • Encode any categorical column — one-hot, ordinal, frequency, target, or binary.

2Cleaning and feature engineering

Domain knowledge beats generic code — the car dataset proves it twice.

Two moves carry the cleaning notebook: the Name column hides a pattern (brand first, model second — split it into two columns), and missing Mileage on electric cars isn't missing at all (impute EV mileage as 0 plus a mileage_missing flag, so the model learns the difference between "zero" and "unknown"). Only 4 rows get removed outright; the analysis section then confirms the cleanup worked.

split, don't drop

A compound column (Brand Model) is two features wearing a trench coat — separate them before encoding.

flag the fill

Whenever you impute, add a missing-indicator column. "Was absent" is itself information a model can use.

high-cardinality preview

Brand/Model end up nominal with too many values for one-hot — the notebook reaches for binary encoding (§7's territory).

3Missing values

Most algorithms can't handle holes — four rungs of fixes, simplest first.

Missing data is simply the absence of values, and most ML algorithms refuse it. The ladder, from the notebook:

Drop

Complete-case analysis: delete rows with holes. Honest, but NULL-heavy columns will eat your dataset.

SimpleImputer

One fixed statistic per column — mean/median for numbers, most-frequent for categories.

KNNImputer

Fill from the k most similar rows by other features — neighbors vote on the missing value.

Iterative (MICE-like)

Model each gappy feature as a function of the others, round-robin, until the fills stabilize.

Then the advanced rung: custom domain imputers — a plain function, then a class, then a scikit-learn-style estimator — because no generic imputer knows that electric cars have no mileage. General tools first, domain rules where they pay.

from sklearn.impute import SimpleImputer, KNNImputer, IterativeImputer SimpleImputer(strategy='median') # numbers: median beats mean on skew KNNImputer(n_neighbors=5) # borrow from similar rows

4Outliers

Extreme observations that deviate from the majority — find them three ways, then decide.

4.1 Detect: eyes, IQR, z-score

Boxplots of Kilometers, Power, and Engine show the suspects; the IQR rule (Q1 − 1.5·IQR … Q3 + 1.5·IQR) and z-scores confirm them numerically.

The NaN trap in handmade IQR

np.percentile() propagates NaNs — one missing value makes Q1/Q3 (and hence both bounds) NaN, and every comparison silently returns False. Handle missing values before outlier detection, or use NaN-aware functions.

4.2 Handle: remove or winsorize

Three strategies, escalating gentleness: remove obvious errors, cap (winsorize) extremes at chosen percentiles, or transform (§6) so the tail stops mattering. The notebook's takeaway is blunt: with extreme outliers distorting everything, winsorizing with the module's OutlierHandler often beats fancier fixes.

lower = Q1 - 1.5 * IQR # below this: suspect upper = Q3 + 1.5 * IQR # above this: suspect

5Scaling numeric features

Same numbers, comparable magnitudes — but only when the model cares.

Must scale

KNN, SVM, linear/logistic regression, neural nets, PCA, K-means — anything using distances or gradient steps.

Mostly needn't

Tree-based models split one feature at a time — magnitude never enters the comparison.

Min-Max

Squashes to a fixed range, usually [0, 1]. Preserves distribution shape but lets one outlier compress everything.

Standardization

Mean 0, std 1 (z-scores). The default when features look roughly normal.

Robust

Median and IQR instead of mean and std — the scaler that shrugs at outliers.

6Transforming numeric features

Change the shape, not just the scale.

Log

Tames positive skew (long right tail) toward normal — the classic fix for prices and counts.

Box-Cox / power

Reduce skew and stabilize variance; more normal-like input, better model behavior.

Binning

Continuous → categories: less noise, and a way to hand linear models non-linear effects.

Polynomial

Expand features into combinations so linear models can learn curves.

7Encoding categorical features

Five tools, one decision: how many categories, and are they ordered?

One-hot

Binary column per category. Perfect for low-cardinality nominal features; explodes on high-cardinality ones.

Ordinal

Ordered categories → integers that respect the order (Low < Medium < High).

Frequency

Replace each category with how often it appears — one column, no explosion.

Target

Replace each category with the mean target for it — leaks signal directly, handle with cross-validation care.

Binary

High-cardinality nominals (hello, Brand/Model) → compact binary columns.
